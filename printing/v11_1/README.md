# 念念 V11.1 · 整体双仓壳

一个壳体同时放板子和电池；一片可拆后盖，两个独立防脱按键帽，一块电池承托垫片。屏幕左、雏菊右，USB 与按键在屏幕这一半的下沿。BOOT 与 RESET 是板上按键，并非独立断电开关。

配色：**壳与后盖蓝色、花瓣白色、花心黄色、花柄及叶片黑色**。V11.1 修复了 V11 按键帽无法穿过闭孔的问题，当前仍是分件打印、粘装花件。实际颜色以机器内耗材及发送时选择的料槽为准。

## 已打印旧版 00 时如何验证

旧 V11 的 00 可检查整板定位、厚度和 USB 插入。旧孔是闭孔，而帽子两端有止挡，无法装入，这是模型安装路径的疏漏，不要硬塞。V11.1 已改为从后方开口落入帽子、由后盖的小舌片封住安装口。帽子、垫片和花件几何没有改变，已打印的可复用。

对正在打印的旧 00：先断电放板子，确认屏幕面与开窗方向、板子不硬顶，贴合后盖试件，再用实际 USB 线检查能否插到底并正常供电。这两项通过只能说明板子与 USB 初步适配，不能代替新版按键滑动和回弹验证。

## 已有花件和两颗帽子后，还要打印什么

`07_剩余蓝色三件合打一盘_V11p1.3mf` 只含：整体前壳、后盖、电池垫片。适用于现场 X1 Carbon 的 256 mm 平台，模型总占地约 216.2×55.8 mm，沿 X 摆放在 10～226.2 mm 内。

不要再打印 01、02、03，否则会重复。合打盘不带自动支撑设置：后盖需要支撑，切片后检查底面、限位柱和挂耳通道；前壳与垫片平底贴平台。若不会为单个对象设支撑，可以先启用自动支撑并检查它主要生成在后盖下方。蓝色三件是一次打印任务；新帽子的装配与实际回弹仍未实测，不能保证整壳一次装配成功。

## 从零开始先打哪份

**先用 `00_整板定位与按键帽试装.3mf`。** 旧 V10 的局部边条试片尚未确认适配，不能据此直接打印新整壳。

00 包含完整屏框定位试件、对应后盖试件和两颗按键帽。与旧试片不同，整板定位框可同时检查长宽、屏幕承托高度和 USB 位置。试件的切边不是正式闭合侧壁，仍需手扶后盖对齐，不代表完整外壳扣合结构。

1. 保持断电，不接电池。屏幕朝向开窗，从壳内放入板子，不要把侧壁横压在 PCB 背面。
2. 两个帽子从后方 U 形安装槽放入，外侧帽头在外、限位肩在内，细杆对着对应的小按键；后盖合上后封住槽顶。不要从外面强塞。
3. 贴合后盖试件，检查没有硬顶屏幕、排针或铜柱。不要强行夹紧。
4. 插入实际 USB 线，应能完全插入、不顶帽头。分别轻按两颗帽子，应能触发并松开；若卡住或按钮持续被压住，停止使用并反馈尺寸。
5. 帽子与孔的滑动间隙也要实测，不要将 STL 的几何检查视为真实按压验证。

## 打印

- 单位毫米，比例 100%；选择现场 X1 Carbon、实际喷嘴和实际 PLA。0.4 mm 喷嘴、0.20 mm 层高作为试打起点。
- 3MF 只含模型与摆放，缺少拓竹专用预设时会提示仅导入几何，这不等于空文件。导入后另选真实机器和材料，再切片。
- 前壳开口朝上；垫片平放。按键帽外帽头贴平台、杆朝上，建议小件加约 3 mm 裙边，取下后清理边缘。
- 后盖小猪与挂耳朝上；限位柱和内侧区域悬空，需要按切片结果加支撑。挂耳通道内的支撑应能清除。
- 花件平背面贴平台，圆润面朝上；不必开启多色自动换料，三种花件分别打印。

## 装配

1. 前壳放在柔软洁净垫上，开口朝上。先从后方 U 形槽落入两颗帽子，再装主板，屏幕对准左边开窗。
2. 帽头在壳外阻止过按，内部肩部阻止向外脱落。小按钮提供的回弹能力有限，实际滑动及回弹必须试装确认；不要粘住帽子或按键。
3. 垫片放进右仓底部。名义厚度 **3.4 mm**，按电池整包 50×34×6 mm、0.3 mm 软绝缘垫和 0.5 mm 后方余量计算。实际厚度变更后重新生成，不靠强压盖子消除晃动。
4. 电池放在垫片及薄软绝缘垫上；引线经中部走线缺口接板子。垫片只用于机械承托，不是电气触点。电池供电仍由电源线连接。
5. 合盖前检查极性、线头空间及没有夹线。后盖的四个短柱对应铜柱，只做限位。必要软垫需逐处实测，不能压元件或显示面。
6. 后盖沿用中心两处 M1.6 螺丝连接；约 M1.6×5 mm 仅为试装起点，先核对实际孔深和有效牙长。不得用螺丝强拉合盖。
7. 花瓣、花心、黑色枝叶最后定位粘贴。打印、修整或上胶时移开电池和电子件。

## 参数与验证范围

- 外形主体 79×55.8×12 mm，挂耳、浮雕及按键帽局部凸出另计。保留两侧黄色塑料座的估算包络；实物厚度仍须核对。
- `params.json` 可编辑电池整包厚度、板子及屏幕尺寸、孔位、按键间隙等。垫片厚度由净腔、整包厚度及预留间隙计算。
- 按键名义空行程 0.35 mm、帽头最大内行程 0.50 mm；这些是 CAD 初值，未测量真实按钮行程和打印摩擦。
- 以原厂 STEP 计算静态干涉、按键帽在两个位置与外壳和 USB 的间隙，以及向内过按/向外拔出的止挡。
- **尚未实际打印 V11、尚未确认整板适配、按键回弹、电池装配和挂耳承重。** 完成 00 试装前，01～03 不应直接批量打印。
